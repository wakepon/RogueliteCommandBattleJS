## 1. 戦闘システム
### 1.1 **パーティ構成：** 1人 ~ 3人のユニットで構成。
* 初期は1人パーティー
* ダンジョンをクリアすると、2人、3人パーティーでのダンジョンプレイが解放される
### 1.2 **攻撃の種類：** 武器か魔法を選んで攻撃
* 単体、隣接何体かを同時に、全体、ランダム数回。
### 1.3 **パンチ**
* 武器の使用回数が減った場合でも何かできるように無限使用回数のパンチ
* power値は1（STR x 1 = STR分のダメージ）、variance（ブレ幅）が設定されている。
### 1.4 **ダメージ計算：**
MVP実装のダメージ計算式:

```
最終ダメージ = (Str/Int + レリックstatBonus) x (power + weaponDamageBonus) x バフ倍率 x レリック倍率 + ブレ補正(±variance)
```

* ブレ補正は加算方式。各武器/魔法にvariance値が設定されており、`-variance ~ +variance` の整数が均等分布で生成され、基礎ダメージ(floor済み)に加算される。乗算方式ではない。

* **戦闘ペース：** 1戦闘は平均3ターン程度。ダンジョンクリアまでにトータル45回分の攻撃リソースが必要。
*
## 2. 武器・魔法
* **武器の特性：**
    * 攻撃力と攻撃対象への特殊効果。
    * 使用回数：平均3〜8回程度。
    * 回数変化：使うほどに強くなる/弱くなる武器。
    * 特殊例：経験値消費、HP/MP変換、敵撃破でMP回復、MPを奪う、相手の攻撃力を上げる
    * lifesteal効果を持つ武器が存在する（吸血の刃）。
    * 全体攻撃(enemyAll)の武器が存在する（投げナイフ、旋風の刃）。
* **魔法の特性：**
    * 使用回数：平均3〜8回程度。
    * 効果の例:単体ダメージ、全体ダメージ、回数ダメージ、ゴールド獲得倍化、敵撃破で経験値プラス1、対象者の次の攻撃を全体化、スカラ・ルカニ的な魔法（バフ/デバフ）、盗む（MP $\rightarrow$ お金）。
* 武器・魔法には **呪い**、**祝福**がついている場合もある。
* 呪い
    * MP使用量25%増加
    * 使用のたびに1ダメージを受ける
* 祝福
    * MP使用量25%減少
    * 基礎ダメージ x 1.5倍
    * 基礎ダメージ + 50
    * 装備枠+1

## 3. ポーション(消耗アイテム)
* **種類：** ステータス上昇（一時的もしくはダンジョン内で永続だが微量）、武器、魔法への永続バフ
* **役割：** お金で購入し、MP/HPなどに変換するリソースとしても機能。

## 4. バフ
* MVP実装されているバフ:
    * **マッスルアップ** Str加算、戦闘終了まで持続
    * **力溜め** 次の攻撃まで有効（主に敵が使用）
* シールドはレリック「壊れかけの鎧」(firstHitShield)として実装されている（最初の被弾を防ぐ）。
* 毎ターン回復はレリック「再生のコケ」(regenPerTurn)として実装されている。
* 「強化」「知力アップ」はMVP未実装。

## 5. デバフ
* MVP実装されているデバフ:
    * **毒** スタック制。毎ターン固定ダメージ、スタックは毎ターン1減少し0になると解除される。
* 「出血」はMVP未実装。

## 6. 討伐ターン
* ターン制限はStageパターンごとに固定値として設定されている（例: stage_1は5, stage_7は12）。
* 討伐ターン数を過ぎてしまうと、超過ターンに応じてペナルティダメージが指数的に増加する。

## 7. 戦闘後の報酬
* 基礎ゴールドがもらえる
    * 雑魚 3ゴールド
    * エリート敵 5ゴールド
    * ボス 10ゴールド
* 現在所持しているゴールド5ゴールドにつき1ゴールドの利息がもらえる(利息上限5ゴールド)
* 報酬は BaseGold + Interest + StolenGold のみ（討伐数分のゴールドボーナスは存在しない）。

## 8. 経験値
* 敵を倒すと1体につき1経験値が一律加算される（討伐ボーナスの仕組みは存在しない）。
* 倒した瞬間に経験値を入手し、戦闘中でもレベルアップが発生する場合もある
* レベルアップタイミングは次のユニットの行動前
