## 1. ダンジョン構造

* **構造：** 全11ステージ構成（第一階層: Stage 1-7、第二階層: Stage 8-11）。Stage 4とStage 9がイベントステージ、Stage 7が第一階層ボス、Stage 11が最終ボス。実質9戦闘+2イベントで1ダンジョン。
* **バリエーション：** ダンジョン自体は同じにして、ユニットの組み合わせパターンでボリュームを出す。
    * クリア後には高難度バージョン（未実装）
    * 各ダンジョンごとに固定のパーティーで挑む
    * 各ダンジョンごとに異なる敵のセット
* 敵との戦闘後に毎回ストアでの購入フェーズが挟まる（Balatro方式）

### イベントステージ

* Stage 4とStage 9はイベントステージ。休憩/宝箱/武器修理から1つを選択する。

### 第二階層（Stage 8-11）

* Stage 8, 10, 11は戦闘ステージ。Stage 9はイベントステージ（Stage 4と同様）。
* 第二階層では敵HP倍率・敵攻撃力倍率が適用される（Tuning Editorで調整可能）。
* **Stage 8編成テーブル（turnLimit=10）:**
  * [オーク + アサシン]
  * [スリープタイガー + ダークメイジ]
  * [オークロード + オーク]
* **Stage 10編成テーブル（turnLimit=10）:**
  * [アサシン + ダークメイジ + ゴブリン]
  * [オークロード + オーク + シャーマン]
  * [スリープタイガー + オーク + ヘドロスライム]
* **Stage 11編成テーブル（turnLimit=14）:**
  * [ドラゴン + オークロード]
  * [ドラゴン + アサシン]
  * [ドラゴン + ダークメイジ]

### マップ画面

* ステージ間にマップ画面を表示。次のステージのプレビューを確認可能。

## 2. 部屋の種類と進行

* ステージは固定の直線進行。
* イベントステージ（Stage 4・Stage 9）では以下の3つの行動から1つを選択する。
* **行動の種類：**
    * 休憩 : パーティー全員のHPを回復（各メンバーが自身の最大HPの50%を回復。回復量はTuning Editorで調整可能）
    * 宝箱
    * 武器修理 : キャラクター単位の選択方式。1人を選択するとそのキャラクターの全武器の使用回数を全回復。
