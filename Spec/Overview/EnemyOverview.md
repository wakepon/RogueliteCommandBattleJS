## 1. 敵の設計
* **表示要素：** HPバー、バフ、デバフ、次ターンの行動予告（EnemyIntent）。EnemyIntent型が実装されており、敵の次ターンの行動と予測ダメージが表示される。
* **敵の種類数（MVP実装済み: 14種）:**
    * **normal（雑魚）:** スライム、ゴブリン、どぶネズミ、ヘドロスライム、シャーマン、妖精、盾持ちゴブリン
    * **elite（エリート）:** オーク、アサシン、スリープタイガー、ダークメイジ、ガーディアン
    * **boss（ボス）:** ドラゴン、リッチ
    * オークロードは削除済み。ゴーストは未実装。
* **敵の行動決定:** 確率ベースのウェイトテーブルで決定される（固定ループパターンではない）。全敵のbehaviorは "attack" に統一されており、行動分岐はEnemyAI.ts内で敵IDごとに個別実装されている。行動バリエーションは「通常攻撃、力溜め、連続攻撃、仲間呼び（召喚）、仲間鼓舞（味方全員に力溜め付与）、自己回復、味方回復、弱体デバフ複合（攻撃＋weakness同時付与）、自己防御バフ、AoE（全体攻撃）、MPドレイン、武器封印、シールド付与、庇う、vulnerability付与、無制限召喚」を含む。
* **ターゲット選択:** 前衛（front）と後衛（back）の重み付き確率選択。前衛は後衛の2倍の確率で狙われる。

### 各敵の行動パターン（MVP実装）
* **スライム:** 100%体当たり（固定行動）。
* **ゴブリン:** 60%斬りつける、40%力溜め（力溜め中は渾身の一撃）。
* **オーク:**
  * 通常時: 60%力溜め、40%こづく。
  * 力溜め中: 100%渾身の一撃（力溜めを消費）。
* **ドラゴン（フェーズ1, HP > 50%）:** 50%切り裂く爪、30%自己再生（最大HPの30%回復）、20%火炎ブレス（AoE全体攻撃）。
* **ドラゴン（フェーズ2, HP <= 50%）:** 30%怒りの爪、30%猛火のブレス（AoE）、40%力溜め。
* **どぶネズミ:** 未召喚時 かみつく60% / 仲間呼び40%。召喚後は100%かみつく（1戦闘1回制限）。
* **ヘドロスライム:** 泥かけ（攻撃＋weakness同時付与）50% / 体当たり50%。
* **シャーマン:** 仲間鼓舞（他の生存敵全員に力溜めを付与）50% / 弱体の呪い（vulnerability付与）30% / 杖で殴る20%。
* **妖精:** ヒール（最もHP割合が低い味方を回復、percentOfMaxHp: 0.3による最大HPの30%回復）80% / タックル20%。
* **盾持ちゴブリン:** 100%小突く（ダメージ＋自身にシールド付与）。
* **アサシン:** 急所狙い55% / 二連撃45%。
* **スリープタイガー:** フェーズ1（HP > 80%）寝返り100%、フェーズ2（HP ≤ 80%）怒りの爪35% / あばれる20% / 乱れ引っかき（3連撃、各hitランダムターゲット）25% / 力溜め20%。力溜め中はフェーズ無関係に大暴れ（2連撃、力溜め消費）。HP80%以下で表示名が「マッドタイガー」に変更（transformName）。
* **ダークメイジ:** MPドレイン35% / 武器封印35% / ダークショット30%。
* **ガーディアン:** 守護の盾（味方にシールド付与）40% / 庇う30% / 体当たり30%。
* **リッチ（フェーズ1, HP > 50%）:** MPドレイン全体35% / 呪い（weakness付与）35% / ダークショット30%。
* **リッチ（フェーズ2, HP ≤ 50%）:** 武器封印全体35% / 暗黒ブレス（AoE）35% / 召喚（ヘドロスライム、回数無制限）30%。

### EnemyActionResult の行動カテゴリ

| カテゴリ | 説明 |
| :--- | :--- |
| 召喚（仲間呼び） | 同種の敵を戦場に追加する。hasSummonedフラグにより1戦闘1回制限。 |
| 無制限召喚（unlimitedSummon） | 回数制限なしで召喚を行う（リッチのフェーズ2）。 |
| 仲間鼓舞 | 他の生存中の味方敵全員に力溜めバフを付与する。 |
| 自己回復 | 自分のHPを回復する。 |
| 味方回復 | 最もHP割合が低い味方敵のHPを回復する。 |
| AoE（全体攻撃） | プレイヤーパーティー全員にダメージを与える。 |
| 弱体デバフ複合（攻撃＋weakness） | 攻撃とweaknessデバフ付与を同時に行う（ヘドロスライムの泥かけ）。 |
| 弱体デバフ（weakness） | プレイヤーのダメージを低下させる持続ターン制デバフを付与する。 |
| 被ダメ増加（applyVulnerability） | vulnerabilityデバフを付与（シャーマンの弱体の呪い）。 |
| 自己防御バフ（selfDefense） | 自分への被ダメージを軽減するバフを付与する。 |
| MPドレイン（mpDrain） | プレイヤーのMPを吸収する。 |
| 全体MPドレイン（mpDrainAll） | パーティー全員のMPを吸収する（リッチ）。 |
| 武器封印（weaponSeal） | ターゲットの武器を封印する（ダークメイジ）。 |
| 武器封印全体（weaponSealAll） | パーティー全員の武器を封印する（リッチのフェーズ2）。 |
| シールド付与（applyShieldToSelf） | 自身にシールドを付与する（盾持ちゴブリン）。 |
| シールド付与（applyShieldToAlly） | 味方にシールドを付与する（ガーディアン）。 |
| 庇う（applyGuard） | 味方への攻撃を代わりに受ける（ガーディアン）。 |
| ランダムターゲット連撃 | 複数回攻撃し、各ヒットでランダムにターゲットを選択する（スリープタイガーの「乱れ引っかき」）。 |
