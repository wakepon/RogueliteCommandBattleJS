## 1. 敵の設計
* **表示要素：** HPバー、バフ、デバフ、次ターンの行動予告（EnemyIntent）。EnemyIntent型が実装されており、敵の次ターンの行動と予測ダメージが表示される。
* **敵の種類数：**
    * 雑魚、エリート、ボスの3種類
    * 各階層ごとに異なる敵セット
    * 各階層ごとに3〜5種類の雑魚敵、1〜2種類のエリート敵、1種類のボス敵
    * 雑魚:40種類、エリート:10種類、ボス:10種類程度を想定
* **MVP実装済みの敵:** スライム(normal)、ゴブリン(normal)、オーク(elite)、ドラゴン(boss)の4種に加え、どぶネズミ(normal)、ヘドロスライム(normal)、シャーマン(normal)、妖精(normal)、アサシン(elite)、スリープタイガー(elite)、ダークメイジ(elite)、オークロード(elite)の8体が追加実装されており、合計12種。ゴーストは実装されていない。
* **敵の行動決定:** 確率ベースのウェイトテーブルで決定される（固定ループパターンではない）。全敵のbehaviorは "attack" に統一されており、行動分岐はEnemyAI.ts内で敵IDごとに個別実装されている。行動バリエーションは「通常攻撃、力溜め、連続攻撃、仲間呼び（召喚）、仲間鼓舞（味方全員に力溜め付与）、自己回復、味方回復、弱体デバフ複合（攻撃＋weakness同時付与）、自己防御バフ、AoE（全体攻撃）、MPドレイン」を含む（毒攻撃・何もしないは削除済み）。
* **ターゲット選択:** 前衛（front）と後衛（back）の重み付き確率選択。前衛は後衛の2倍の確率で狙われる。

### 各敵の行動パターン（MVP実装）
* **スライム:** 100%体当たり（固定行動）。
* **ゴブリン:** 60%斬りつける、40%振りまわす。
* **オーク:**
  * 通常時: 60%力溜め、40%こづく。
  * 力溜め中: 100%渾身の一撃（力溜めを消費）。
* **ドラゴン（フェーズ1, HP > 50%）:** 50%切り裂く爪、30%自己再生（HP回復）、20%火炎ブレス（AoE全体攻撃）。
* **ドラゴン（フェーズ2, HP <= 50%）:** 30%怒りの爪、30%猛火のブレス（AoE）、40%力溜め。
* **どぶネズミ:** 未召喚時 かみつく60% / 仲間呼び40%。召喚後は100%かみつく（1戦闘1回制限）。
* **ヘドロスライム:** 泥かけ（攻撃＋weakness同時付与）50% / 体当たり50%。
* **シャーマン:** 仲間鼓舞（他の生存敵全員に力溜めを付与）45% / 杖で殴る55%。
* **妖精:** ヒール（最もHP割合が低い味方を回復）80% / タックル20%。
* **アサシン:** 急所狙い55% / 二連撃45%。
* **スリープタイガー:** フェーズ1（HP > 80%）寝返り100%、フェーズ2（HP ≤ 80%）怒りの爪50% / あばれる25% / 力溜め25%。力溜め中はフェーズ無関係に大暴れ（2連撃、力溜め消費）。
* **ダークメイジ:** MPドレイン40% / ダークショット60%。
* **オークロード:** 鼓舞35% / 小突く45% / ガード20%。

* **敵の種類例：**
    * やられ役の弱い敵
    * 回復する敵
    * バフを唱える敵
    * 呪文を封じてくる敵
    * 壁になる敵
    * 全体攻撃してくる敵
