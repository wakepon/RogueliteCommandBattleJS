# 敵パターン設計案

## ステータス: 導入推奨

全13体の敵パターン案。カテゴリA（純粋アタッカー7体）とカテゴリB（バフ/デバフ持ち6体）に分類。
毒などの状態異常は使用しない。

---

## バランス基準値

| 項目 | 値 |
|------|-----|
| プレイヤー合計HP | ~130 (戦60 + 魔30 + 聖40) |
| パーティ火力/turn | 序盤30~50、中盤40~70 |
| ターン制限 | 5~12（ステージ依存） |
| 回復手段 | Heal +15HP (5MP)、Regen Moss +2HP/turn |

---

## カテゴリA: 純粋アタッカー

特殊な技を持たず、直接ダメージでプレイヤーを脅かす敵。

---

### A-1. スライム（改造）

| 項目 | 値 |
|------|-----|
| **ランク** | 雑魚 |
| **HP** | 18 |
| **ATK** | 4 |
| **AGI** | 2 |

**行動パターン:**

| 行動 | ダメージ | 確率 |
|------|---------|------|
| 体当たり | 3 | 100% |

**平均ダメージ:** 3.0/turn

**考案意図:** 最弱の敵。行動が完全に予測可能で、プレイヤーにシステムを学ばせるチュートリアル的存在。複数体で出現すると削りが蓄積し、武器の耐久管理を意識させる。

## カテゴリB: バフ/デバフ持ち

自己バフ、味方バフ、プレイヤーデバフで戦場を支配する敵。
**注意:** 一部の行動は `EnemyActionResult` の拡張が必要（後述）。

---

### B-1. ゴブリンシャーマン（新規）

| 項目 | 値 |
|------|-----|
| **ランク** | 雑魚 |
| **HP** | 20 |
| **ATK** | 3 |
| **AGI** | 5 |

**行動パターン:**

| 行動 | ダメージ | 確率 | 効果 |
|------|---------|------|------|
| 仲間を鼓舞する | 0 | 45% | 他の味方全員にATKバフ+2（2ターン） |
| 杖で殴る | 4 | 55% | |

**平均ダメージ:** 直接 2.2/turn + 味方バフによる間接ダメージ増加

**考案意図:** 単体ではほぼ無害だが、放置すると味方全体の火力がじわじわ上がる「増幅器」。ATKバフ+2は既存のバフシステム（value×0.1倍率）で +20%相当。「シャーマンを先に倒すか、火力の高い敵を先に倒すか」のターゲティング判断を生む。ゴブリンと一緒に出現させることで、ゴブリンの攻撃力5~7が6~8.4に上がる程度の、緩やかだが無視できない脅威。

## 必要なシステム拡張

カテゴリBの敵を実装するには、`EnemyActionResult` に以下のフィールド追加が必要:

```typescript
interface EnemyActionResult {
  // 既存フィールド
  actionName: string
  damage: number
  hits: number
  poisonStacks: number   // 現在未使用だが互換性のため残す
  mpDrain: number        // ダークメイジ、リッチキングが使用
  applyCharge: boolean
  consumeCharge: boolean

  // 新規フィールド
  buffAllies?: {           // 味方全体バフ（シャーマン、キャプテン、リッチキング）
    type: 'atk' | 'charge' // バフの種類
    value: number           // ATKバフの場合の値
    duration: number | 'battle'
  }
  debuffPlayer?: {         // プレイヤーデバフ（ウィスプ、リッチキング）
    type: 'str' | 'int' | 'all'
    value: number           // 減少量
    duration: number
  }
  selfBuff?: {             // 自己バフ（バーサーカー、キャプテン）
    type: 'atk' | 'defense'
    value: number
    duration: number | 'battle'
  }
}
```

### ターゲティング判断の設計意図

各敵の組み合わせで「誰を先に倒すか」の判断が異なるよう設計:

| 組み合わせ例 | 最優先ターゲット | 理由 |
|-------------|---------------|------|
| コウモリ + ゴブリン | コウモリ | 低HPで倒しやすく、先制2hitが痛い |
| オーク + シャーマン | シャーマン | 放置するとオークの火力が上がる |
| アサシン + ナイトキャプテン | アサシン | 号令で12dmg→15.6dmgに化ける前に排除 |
| バーサーカー + ダークメイジ | バーサーカー | 永続バフが蓄積する前に倒す |
