## ステータス: 導入推奨

全13体の敵パターン案。カテゴリA（純粋アタッカー7体）とカテゴリB（バフ/デバフ持ち6体）に分類。
毒などの状態異常は使用しない。

---

## 現行システムの制約

### 使えるもの（EnemyActionResult 既存フィールド）

| フィールド | 説明 | 使用状況 |
|-----------|------|---------|
| `damage` | 直接ダメージ | 全敵が使用 |
| `hits` | 攻撃回数（1=通常、3=連続攻撃） | ドラゴンが使用 |
| `mpDrain` | プレイヤーMP削減 | **未使用**（実装済み） |
| `applyCharge` | 自身に力溜めバフ付与（次の攻撃2倍） | オーク・ドラゴンが使用 |
| `consumeCharge` | 力溜めバフ消費 | オーク・ドラゴンが使用 |

### 使えないもの（システム拡張が必要）

| 機能 | 現状 |
|------|------|
| 味方（他の敵）へのバフ | 仕組みが存在しない |
| プレイヤーへのSTR/INTデバフ | Debuff型が `type: 'poison'` 固定 |
| 敵の防御バフ | 仕組みが存在しない |
| AGI（先制の概念） | データは残るがロジックで一切参照されない |
| ATK（攻撃力ステータス） | EnemyAIのダメージは全てハードコード。ATKは不使用 |

### 敵ステータスの実態

| フィールド | ゲーム上の意味 |
|-----------|--------------|
| `hp` | 有効。敵の耐久力 |
| `attack` | **無効**。ダメージはEnemyAIでハードコード |
| `agi` | **無効**。行動順はフェーズ固定（パーティー→敵） |
| `gold` | 有効。報酬計算に使用 |

→ 以下の設計では **HP** と **gold** のみを有効なステータスとして扱う。ダメージはEnemyAIの行動テーブルで直接指定。

## バランス基準値

| 項目 | 値 |
|------|-----|
| プレイヤー合計HP | ~130 (戦60 + 魔30 + 聖40) |
| パーティ火力/turn | 序盤30~50、中盤40~70 |
| ターン制限 | 5~12（ステージ依存） |
| 回復手段 | Heal +15HP (5MP)、Regen Moss +2HP/turn |
| シールド | 壊れかけの鎧（初撃無効化、1回限り） |
| ターゲティング | 前衛50%/後衛25%（2人後衛時）。祈りで補正 |

## カテゴリA: 純粋アタッカー

特殊な技を持たず、直接ダメージでプレイヤーを脅かす敵。

### A-1. スライム

| 項目 | 値 |
|------|-----|
| **ランク** | 雑魚 |
| **HP** | 18 |
| **Gold** | 3G |

**行動パターン:**

| 行動 | ダメージ | 確率 |
|------|---------|------|
| 体当たり | 3 | 100% |

**平均ダメージ:** 3.0/turn

**考案意図:** 最弱の敵。
