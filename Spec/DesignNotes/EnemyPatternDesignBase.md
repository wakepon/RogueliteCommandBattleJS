# 敵パターン設計案 v2

## ステータス: 導入推奨

全13体の敵パターン案。カテゴリA（純粋アタッカー7体）とカテゴリB（バフ/デバフ持ち6体）に分類。
毒などの状態異常は使用しない。

---

## 現行システムの制約

### 使えるもの（EnemyActionResult 既存フィールド）

| フィールド | 説明 | 使用状況 |
|-----------|------|---------|
| `damage` | 直接ダメージ | 全敵が使用 |
| `hits` | 攻撃回数（1=通常、3=連続攻撃） | ドラゴンが使用 |
| `mpDrain` | プレイヤーMP削減 | **未使用**（実装済み） |
| `applyCharge` | 自身に力溜めバフ付与（次の攻撃2倍） | オーク・ドラゴンが使用 |
| `consumeCharge` | 力溜めバフ消費 | オーク・ドラゴンが使用 |

### 使えないもの（システム拡張が必要）

| 機能 | 現状 |
|------|------|
| 味方（他の敵）へのバフ | 仕組みが存在しない |
| プレイヤーへのSTR/INTデバフ | Debuff型が `type: 'poison'` 固定 |
| 敵の防御バフ | 仕組みが存在しない |
| AGI（先制の概念） | データは残るがロジックで一切参照されない |
| ATK（攻撃力ステータス） | EnemyAIのダメージは全てハードコード。ATKは不使用 |

### 敵ステータスの実態

| フィールド | ゲーム上の意味 |
|-----------|--------------|
| `hp` | 有効。敵の耐久力 |
| `attack` | **無効**。ダメージはEnemyAIでハードコード |
| `agi` | **無効**。行動順はフェーズ固定（パーティー→敵） |
| `gold` | 有効。報酬計算に使用 |

→ 以下の設計では **HP** と **gold** のみを有効なステータスとして扱う。ダメージはEnemyAIの行動テーブルで直接指定。

## バランス基準値

| 項目 | 値 |
|------|-----|
| プレイヤー合計HP | ~130 (戦60 + 魔30 + 聖40) |
| パーティ火力/turn | 序盤30~50、中盤40~70 |
| ターン制限 | 5~12（ステージ依存） |
| 回復手段 | Heal +15HP (5MP)、Regen Moss +2HP/turn |
| シールド | 壊れかけの鎧（初撃無効化、1回限り） |

## カテゴリB: バフ/デバフ持ち

自己バフ、味方バフ、プレイヤーデバフで戦場を支配する敵。

### 必要なシステム拡張

カテゴリBの実装には `EnemyActionResult` の拡張が必要:

```typescript
interface EnemyActionResult {
  // 既存フィールド（変更なし）
  actionName: string
  damage: number
  hits: number
  poisonStacks: number   // 未使用だが互換性のため残す
  mpDrain: number        // ダークメイジ、リッチキングが使用
  applyCharge: boolean
  consumeCharge: boolean

  // === 新規フィールド ===

  // 味方バフ: 他の生存敵全員に力溜めバフを付与
  // （既存の charge バフを流用、新しいバフ型は不要）
  chargeAllAllies?: boolean

  // プレイヤーデバフ: 攻撃対象のダメージ出力を低下
  // Debuff型の拡張が必要: type: 'poison' → type: 'poison' | 'weakness'
  applyWeakness?: {
    value: number        // ダメージ倍率の低下量（例: 0.2 → 20%低下）
    duration: number     // 持続ターン数
  }

  // 自己防御: 次に受けるダメージを軽減
  // 既存のBuff型を流用: { type: 'defense', value: 50, duration: 1 }
  applySelfDefense?: {
    value: number        // 軽減率（%）
    duration: number     // 持続ターン数
  }
}
```

**拡張の規模:**
- `chargeAllAllies`: BattleActionProcessor に10行程度の追加（全生存敵にcharge buffを付与するループ）
- `applyWeakness`: Debuff型の拡張 + DamageCalculatorに弱体倍率の計算追加（~20行）
- `applySelfDefense`: BattleActionProcessor の被ダメージ計算に防御バフチェック追加（~10行）
