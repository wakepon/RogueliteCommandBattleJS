# クラシックRPG感を保つ魔法設計

## ステータス: 検討中（2026-04-12）

WeaponSpellDiversityAnalysis.md の「燃焼/凍結」路線に代わる、ドラクエ/FF風バフ・デバフ魔法による設計案。「いにしえのRPG感」を保ちつつシナジーとリソース管理の緊張を生む。

---

## 核心: なぜバフ/デバフ魔法が答えなのか

### 現状の問題
全7種の魔法が「ダメージを与える」か「HPを回復する」に収まっている。一次元の性能序列（アイスボルト < ファイア < サンダー）になるため、「最強の攻撃魔法+ヒール以外は売る」が合理的。

### バフ/デバフが解決する理由

**バイキルト(DQ)やプロテス(FF)は、新しい状態タグなしで掛け算のシナジーを生む。**

- 力溜め(次の攻撃2倍) = 1ターンの投資 → 以降のリターン
- 燃焼/凍結のような「状態タグの付与と消費」という追加レイヤーが不要
- 既存のBuff/Debuffシステム上に乗せるだけで実装可能
- 「攻撃力UP」「防御力UP」はRPGプレイヤーなら説明不要

### 「魔法を複数持ちたい」が成立する構造

```
現状: [サンダー] [ファイア] [空き→売る] [空き→売る]
理想: [サンダー] [ブレイク] [ファイア] [アイスボルト]
→ 4枠全てが「違う状況で最適解になる」
```

攻撃魔法だけの序列 → 役割の異なる魔法のポートフォリオへの転換。

## 魔法提案: 8種

### A. 攻撃バフ系

#### 力溜め (ちからだめ) — DQバイキルト相当
- id: `charge_spell`, allySingle, mpCost **4**, price 6G, Common
- **効果:** 対象に力溜めバフ付与（次の攻撃2倍）
- **判断:** 僧侶が「ヒールか力溜めか」を毎ターン迫られる
- **シナジー:** 僧侶→戦士の大斧が2倍。キャラ間連携の最もシンプルな形
- **実装:** 既存の`charge`バフタイプ(BuffProcessor.ts)をそのまま利用可能

#### ブレイク — DQルカニ相当
- id: `armor_break`, enemySingle, mpCost **4**, price 7G, Uncommon
- **効果:** 対象の被ダメージ+25%（2ターン）
- **判断:** 魔法使いが「自分で攻撃するか、デバフで全員の攻撃を強化するか」
- **シナジー:** ブレイク→戦士もサンダーも全員1.25倍。ボス戦で特に価値が高い
- **実装:** 敵に新デバフタイプ`vulnerable`が必要（または味方全体バフで擬似実装）

### B. 防御バフ系

#### プロテス — DQスクルト/FFプロテス相当
- id: `protect`, allyAll, mpCost **5**, price 8G, Uncommon
- **効果:** 味方全体の被ダメージ30%軽減（2ターン）
- **判断:** インテント「40ダメ!」を見て、事前にプロテスを張るか、事後にヒールするか
- **シナジー:** ヒールとの「事前防御 vs 事後回復」の択

### C. MP効率差を生む攻撃魔法

#### ファイラ — FFファイラ相当
- id: `fira`, enemySingle, mpCost **6**, power 5, variance 6, price 9G, Uncommon
- **判断:** ファイア(4MP,P4)とサンダー(7MP,P6)の中間。「サンダーを温存してファイラで済ませる」節約判断
- **保持理由:** MPグラデーションの中間層として、「どの火力帯で戦うか」の選択が生まれる

#### ヒーラ (全体回復) — DQベホマラー相当
- id: `heal_all`, allyAll, mpCost **8**, heal 15HP, price 10G, Rare
- **判断:** ヒール(単体30HP,5MP) vs ヒーラ(全体15HP,8MP)。全員被弾後はヒーラの方が効率的
- **保持理由:** 「普段はヒール、AoE被弾後だけヒーラ」の使い分けが両方持つ動機

### D. 攻撃デバフ系

#### スリープ — DQラリホー相当
- id: `sleep`, enemySingle, mpCost **3**, price 5G, Common
- **効果:** 対象の行動を1ターンスキップ
- **判断:** インテント「40ダメ!」の敵を眠らせて、別の敵を先に倒す戦術
- **シナジー:** 安くて軽い(3MP)。道具箱的に「持っておいて、ここぞで使う」
- **実装注意:** 敵の行動スキップ処理が必要。1ターン限定なのでハメにはならない

### E. ユーティリティ系

#### マジックバリア — DQマジックバリア相当
- id: `magic_barrier`, allySingle, mpCost **3**, price 5G, Common
- **効果:** 対象にシールド15付与（次の1回の被ダメを15軽減、消費で消滅）
- **判断:** インテントを見て「一番狙われそうなキャラにバリア」。事前防御
- **シナジー:** ヒール(事後回復)との差別化。インテント読みスキルが報われる

#### ヘイスト — FFヘイスト相当
- id: `haste`, allySingle, mpCost **5**, price 10G, Rare
- **効果:** 対象の次のターン2回行動
- **判断:** 力溜め(1回2倍) vs ヘイスト(2回行動)。高Power武器1本なら力溜め、低Power武器複数なら2回行動の方が強い
- **実装注意:** 2回行動は実装が複雑。Phase 2以降でもよい

## リソース管理の緊張: 具体例

### MP消費シミュレーション

**旧(攻撃魔法のみ):**
```
戦闘1: サンダー(7)+ファイア(4) = 11MP → 残14
戦闘2: サンダー(7)+ファイア(4) = 11MP → 残3
戦闘3: 魔力弾のみ → 判断不要
```

**新(バフ/デバフ込み):**
```
戦闘1(雑魚3体): ファイアストーム(5)+ファイア(4) = 9MP → 残16
  → サンダーで1体ずつ(14MP)vs全体で削る(9MP)→節約判断

戦闘2(エリート): ブレイク(4)+サンダー(7)+ファイア(4) = 15MP → 残1
  → ブレイクで全員1.25倍 vs 自分2回攻撃→パーティDPS最大化の判断

戦闘3: MP1で何も撃てない→MPポーション/休憩の価値が上がる
```

### バトルシナリオ: ボス戦の3つの択

```
ドラゴン(HP100) インテント: 火炎ブレス(全体20ダメ)

案A(攻撃重視):
  戦士: 大斧(49ダメ), 魔法使い: サンダー(42ダメ), 僧侶: 力溜め→戦士
  → 91ダメ。次ターンで倒せるかも。全員20被弾、魔法使い危険

案B(防御重視):
  戦士: 大斧(49ダメ), 魔法使い: ブレイク, 僧侶: プロテス
  → 49ダメ。しかしブレス被ダメ14に軽減。次ターン以降全員1.25倍

案C(ピンポイント防御):
  戦士: 大斧(49ダメ), 魔法使い: サンダー(42ダメ), 僧侶: バリア→魔法使い
  → 91ダメ + 魔法使いの被ダメ15軽減(20→5)

3つ全てに合理性がある。正解は1つではなく、HP/MP/武器残量で変わる。
```

## 実装優先順位

### Phase 1: 最小3種 (シナジーの骨格)

| 魔法 | 使用者 | 生まれる判断 |
|------|--------|------------|
| **力溜め** | 僧侶 | 「ヒールか力溜めか」 |
| **ブレイク** | 魔法使い | 「攻撃かデバフか」 |
| **プロテス** | 僧侶 | 「守りに回るか」 |

→ 僧侶の3枠が「ヒール/力溜め/プロテス」で埋まり、毎ターン3択
→ 魔法使いの「攻撃魔法+ブレイク」で攻撃と支援の二軸

### Phase 2: +3種 (選択肢拡張)
ファイラ、ヒーラ、マジックバリア

### Phase 3: +2種 (状況対応)
スリープ、ヘイスト

## 燃焼/凍結路線との関係

| アプローチ | フィーリング | 実装コスト | シナジー深度 |
|-----------|------------|----------|------------|
| バフ/デバフ | ドラクエ/FF的 | **低** | 中 |
| 燃焼/凍結 | Slay the Spire的 | 中 | 高 |

**推奨:** まずバフ/デバフ(Phase 1)でプレイテスト → 必要なら燃焼/凍結を後から追加。両立可能。
