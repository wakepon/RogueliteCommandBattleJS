# ビルドアーキタイプ案 10種

## ステータス: 提案（2026-04-13）

---

## 1. 一撃必殺 / Alpha Strike
**幻想:** 「毎ターンお膳立てし、たった一撃で敵を消し飛ばす」

- **関与キャラ:** 僧侶→戦士にバフ、魔法使いは独立
- **コア:** 力溜め(×2) × 精密(確定ダメ) × レリック倍率 を乗算して一撃必殺
- **強み:** エリート・ボスを行動前に処理。STR7×P8×力溜め2.0 = 112。魔法の鏡(×2.5)で140超
- **弱み:** セットアップに1ターンかかる。複数雑魚にはオーバーキル。僧侶がヒール不能
- **必要アイテム:** 重撃のハンマー, 力溜め魔法, 精密, 魔法の鏡, 戦士の腕輪/英雄の証
- **ターン例:**
  1. 戦士:パンチ / 魔法使い:ファイア / 僧侶:力溜め→戦士
  2. 戦士:ハンマー(112ダメ!) / 魔法使い:ファイア / 僧侶:ヒール
- **新規メカニクス:** なし（既提案の力溜め魔法＋魔法の鏡）

## 2. 不死身の要塞 / Ironclad Fortress
**幻想:** 「何にも殺されない。全ての戦闘をHP満タンで終える」

- **関与キャラ:** 全3人。戦士がタンク＋吸血、僧侶がヒール＋バリア、魔法使いがMP効率攻撃
- **コア:** 祈り(被ターゲット率UP) + 吸血武器 + バリア/ヒール で戦士にダメージを集中させ自己回復
- **強み:** 安定感抜群。ボス戦にHP/MPほぼ満タンで到達。ポーション不要
- **弱み:** 殲滅速度が遅い。ターン制限が天敵。AoE攻撃に弱い
- **必要アイテム:** 吸血の刃, 吸血の大鎌, バリア, ヒール, 再生のコケ, 怒りの鉢巻
- **ターン例:**
  1. 戦士:吸血大鎌(AoE+回復) / 魔法使い:魔力の矢 / 僧侶:祈り→戦士
  2. 戦士:吸血の刃 / 魔法使い:魔力の矢 / 僧侶:ヒール→戦士
- **新規メカニクス:** なし

## 3. 魔力暴走 / Mana Overdrive
**幻想:** 「魔力の時限爆弾。全MPを溜めて最後に解き放つ」

- **関与キャラ:** 魔法使い中心。僧侶は回復、戦士は独立
- **コア:** 道中はMP効率重視 → ボス戦でマナバースト(MP全消費、MP×3ダメ)
- **強み:** 最高の瞬間火力。MP25でマナバースト=75ダメ。賢者の杖+大魔導師帽で通常魔法も超強化
- **弱み:** マナバースト後はMP0で魔力弾のみ。魔法使いが死ぬとビルド崩壊
- **必要アイテム:** マナバースト, MPドレイン, サンダー/ファイラ, 大魔導師の帽子, 賢者の杖
- **ターン例(ボス戦):**
  1. 戦士:グレートソード / 魔法使い:サンダー(MP25→18) / 僧侶:精密→魔法使い
  2. 戦士:グレートソード / 魔法使い:マナバースト(MP18→0, 54ダメ) / 僧侶:ヒール
  3. 戦士:パンチ / 魔法使い:魔力弾(MP0) / 僧侶:祈り
- **新規メカニクス:** なし（既提案のマナバースト＋MPドレイン）

## 4. 毒蝕の霧 / Creeping Miasma
**幻想:** 「強く殴らなくていい。毒で溶かすだけ」

- **関与キャラ:** 全3人で毒スタック積み。魔法使い:ポイズンクラウド、僧侶/戦士:毒の短剣
- **コア:** 毒スタック × 毒の知識(毒ダメ2倍) で全敵にDoT。防御しながら待つ
- **強み:** ゴールド効率最高。毒短剣4Gが全ラン通して活躍。複数敵戦に強い
- **弱み:** 殲滅が遅くターン制限に弱い。敵ヒーラー(妖精)がいると毒を相殺される
- **必要アイテム:** 毒の短剣(×2), ポイズンクラウド, 毒の知識, バリア/ヒール
- **ターン例:**
  1. 戦士:毒短剣→A(毒+2) / 魔法使い:ポイズンクラウド(全敵毒+3) / 僧侶:祈り
  2. 戦士:ショートソード→A / 魔法使い:魔力の矢→A / 僧侶:ヒール
  → 毒の知識ありで、Aは毒5スタック=毎ターン20ダメ(4ダメ/tick)
- **新規メカニクス:** なし（毒は既存。プレイヤー側の毒付与武器/魔法を追加するのみ）

## 5. 黄金の略奪者 / Golden Plunderer
**幻想:** 「戦いは投資。全てのバトルが利益を生む」

- **関与キャラ:** 魔法使い中心(金のまじない)、戦士(黄金の剣)
- **コア:** 金のまじない(+3G/cast) + 商人の護符(+2G/kill) + 貯金箱(利息) で複利的にゴールド増殖
- **強み:** 後半ショップで最高のアイテムを買える。ゴールドが最終的にパワーに変換される
- **弱み:** 序盤が極めて弱い。ダメージの代わりにお金を稼いでいるのでバトルが長引く
- **必要アイテム:** 金のまじない, 商人の護符, 貯金箱/金の指輪, 黄金の剣
- **ターン例:**
  1. 戦士:ショートソード / 魔法使い:金のまじない(14ダメ+3G) / 僧侶:祈り
  2. 戦士:ショートソード / 魔法使い:金のまじない(+3G) / 僧侶:ヒール
  → 1戦で+6G(まじない) + +4G(2キル×商人護符) = +10Gボーナス
- **新規メカニクス:** なし

## 6. 怒りの狂戦士 / Berserker's Wrath
**幻想:** 「痛みが力になる。死にかけの方が強い」

- **関与キャラ:** 戦士中心。僧侶がHP精密管理(回復しすぎない)。魔法使いはバリア担当
- **コア:** 呪いの槍(HP消費武器)で自らHPを下げ、怒りの炎(HP30%以下×1.5) + 鬼神の面(HP50%以下×1.25)を同時発動
- **強み:** 条件付き倍率が掛け算。怒りの炎×鬼神の面 = ×1.875。呪いの槍P6×STR7×1.875 = 78
- **弱み:** HP管理ミスで即死。インテント読みが必須。AoEで全員被弾すると崩壊
- **必要アイテム:** 呪いの槍, 怒りの炎, 鬼神の面, バリア, ヒール
- **ターン例:**
  1. 戦士:呪いの槍(42ダメ, HP-5→55/60) / 魔法使い:ファイア / 僧侶:祈り
  2. 戦士:呪いの槍(HP-5→30/60=50%) / 魔法使い:ファイア / 僧侶:バリア→戦士
  → 鬼神の面発動！次のターン呪いの槍=42×1.25=52.5
  3. 戦士:呪いの槍(HP-5→15/60=25%) / 魔法使い:バリア→戦士 / 僧侶:ヒール→...悩む
  → 怒りの炎も発動！42×1.875=78.75。しかしHPが15...ヒールするか?するとバフ消える
- **新規メカニクス:** なし

## 7. 連撃の嵐 / Thousand Cuts
**幻想:** 「1発は軽い。100発で世界が変わる」

- **関与キャラ:** 戦士中心。僧侶が集中(STR+3バフ)でサポート
- **コア:** 連撃の短剣(2回攻撃) × 武器ダメボーナスレリック多数(砥石+矢筒+紋章=+9/hit)
- **強み:** 数学的に最強。連撃短剣+9bonus: 2hit×(STR7×(P2+9))=2×77=154/use。6use=924総ダメ
- **弱み:** レリック3枠を武器ダメに使うため魔法使いに恩恵ゼロ。戦士の武器が壊れたら終了
- **必要アイテム:** 連撃の短剣, 鋭い砥石, 古びた矢筒, 竜殺しの紋章, 集中
- **ターン例:**
  1. 戦士:連撃短剣(2×77=154) / 魔法使い:ファイア / 僧侶:集中→戦士(STR+3)
  2. 戦士:連撃短剣(2×(10×11)=220!集中中) / 魔法使い:ファイア / 僧侶:ヒール
- **新規メカニクス:** なし（連撃短剣の2回攻撃が実装上の要点）

## 8. 時限爆弾 / Countdown
**幻想:** 「じわじわ刻印を刻み、一気に爆破する」

- **関与キャラ:** 全3人で刻印を積む → 魔法使いが起爆
- **コア:** **新状態「刻印(Mark)」**。敵に蓄積し、「起爆(Detonate)」で刻印数×固定ダメに変換
- **強み:** セットアップ後の爆発力が凄まじい。刻印10 × 5ダメ/刻印 = 50ボーナスダメ
- **弱み:** セットアップに2-3ターン必要。短期決戦では直接攻撃に劣る。敵が死ぬと刻印無駄
- **必要アイテム(全て新規):**
  - 刻銘の剣(戦士武器: 低ダメ+3刻印/hit)
  - 魔力刻印(魔法: MP2, +2刻印)
  - 起爆(魔法: MP5, 刻印×5ダメ, 刻印消費)
  - 起爆の護符(レリック: 刻印が毎ターン1ダメ/刻印のDoTにもなる)
- **新規メカニクス:** **刻印(Mark)** — 敵への新デバフ型。スタック。起爆効果で消費されダメージに変換

## 9. 転生の輪 / Reborn Cycle
**幻想:** 「武器が壊れるたびに、自分が強くなる」

- **関与キャラ:** 戦士中心
- **コア:** **新レリック「努力の証」** — 武器が壊れる(耐久0)たびにSTR+1永続バフ
- **強み:** 自己強化。ラン中に4-6本壊してSTR+4~6。終盤パンチですらSTR13×1=13ダメ
- **弱み:** 安い武器を大量購入するためゴールドが必要。序盤は意図的に弱い武器を使う
- **必要アイテム(レリックは新規):**
  - 努力の証(レリック: 武器破壊時STR+1永続)
  - 研ぎ師の名刺(最後の1撃2倍、壊れる直前に火力UP)
  - 安い武器を大量: 錆びたナイフ, 錆びた大剣, 投げナイフ等
- **面白い判断:** 武器お手入れ用油(耐久温存)は通常最高だが、このビルドでは**逆に邪魔**（壊したいのに壊れない）
- **新規メカニクス:** **weaponBreakStatBonus** — 武器耐久0時に永続STR+1。戦闘を跨いで蓄積

## 10. 指揮官の采配 / Commander's Gambit
**幻想:** 「自分は戦わない。全員を最適に動かす指揮官」

- **関与キャラ:** 僧侶が司令塔。毎ターン誰に「強化指令」をかけるかで全体の動きが変わる
- **コア:** **新魔法「戦術指令」** — 味方1人に「強化指令」バフ。ダメ×1.3 + クラス別追加効果(戦士→吸血3, 魔法使い→敵弱体15%)
- **強み:** 柔軟性最高。敵インテントを見て「今ターンは誰を強化すべきか」を毎回判断
- **弱み:** 僧侶の個人火力ゼロ。実質2人で戦うので純DPSは低い
- **必要アイテム(魔法は新規):**
  - 戦術指令(僧侶魔法: MP3, 味方単体, 強化指令バフ)
  - ヒール(僧侶: 強化指令とヒールの毎ターン択)
  - 戦士/魔法使いの攻撃アイテムは何でもOK
- **ターン例:**
  1. インテント「敵A→戦士に25ダメ」→ 僧侶:戦術指令→魔法使い(弱体で敵ダメ-15%)
  2. インテント「敵A→8ダメ(弱体中)」→ 僧侶:戦術指令→戦士(×1.3+吸血で攻撃&回復)
  3. インテント「敵B→30ダメ!」→ 僧侶:ヒール→戦士(強化指令を捨てて回復優先)
- **新規メカニクス:** **戦術指令(tactical_command)** + **強化指令(empowered)バフ** — クラス別の追加効果付きバフ

## アーキタイプ間の相互関係

**自然な移行:**
- 黄金の略奪者 → どのビルドにも移行可（お金で何でも買える）
- 狂戦士 ↔ 一撃必殺（STR積みを共有、HP管理が分岐点）
- 不死身の要塞 → 毒蝕の霧（どちらも長期戦志向）
- 連撃の嵐 → 一撃必殺（武器ダメボーナスレリックを共有）

**相反する組み合わせ（ショップで悩む）:**
- 不死身の要塞(HP満タン維持) vs 怒りの狂戦士(低HP維持)
- 黄金の略奪者(お金を貯める) vs 転生の輪(安い武器を大量購入)
- 魔力暴走(MPを使い切る) vs 指揮官の采配(僧侶がMP節約したい)

## 新規メカニクスの実装優先度

1. **不要(7/10):** アーキタイプ1-7は既存+既提案アイテムで完結
2. **刻印+起爆(#8):** 新デバフ型1つ + 新魔法効果1つ。中程度の実装量
3. **武器破壊ボーナス(#9):** 新レリック効果1つ。戦闘跨ぎの永続バフが実装のポイント
4. **戦術指令(#10):** 新バフ型 + クラス別条件分岐。最も複雑
