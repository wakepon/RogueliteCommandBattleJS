# 経験値系・防御系 新アイテム提案

## ステータス: 検討中

経験値を戦略に取り込むアイテムと、防御の選択肢を拡充するアイテムの提案。各10個。

---

## カテゴリA: 経験値・レベルアップ関連（10個）

### 設計方針
「誰がトドメを刺すか」「どの順番で敵を倒すか」「レベルアップタイミングをどう活かすか」の判断軸を増やす。必ず何かを犠牲にして経験値を得る、または経験値をトリガーにして何かが起きる構造にする。

---

### 1. 魂喰いの剣
- 種別: 武器
- レア度: Uncommon / 価格: 7G
- 効果: 敵単体, Power3, ブレ±4, 耐久4。**この武器でトドメを刺すと耐久を消費しない**
- デザイン意図: 「トドメ専用に温存するか、DPS用に振るか」の判断を毎ターン迫る

### 2. 知恵の書
- 種別: レリック
- レア度: Rare / 価格: 9G
- 効果: レベルアップに必要な経験値を**1減少**（最低2）
- デザイン意図: 全レベル帯で恩恵があり、早期取得ほどリターンが大きい投資型

### 3. 修羅の証
- 種別: レリック
- レア度: Rare / 価格: 10G
- 効果: トドメボーナスEXPが**+1追加**（通常+1→+2）。ただし**ゴールド報酬-2G**
- デザイン意図: 成長速度 vs 装備充実のトレードオフ。金策ビルドとは完全に相反

### 4. 覚醒の魔弾
- 種別: 魔法
- レア度: Uncommon / 価格: 7G
- 効果: 敵単体, Power3, ブレ±4, MP5。**この魔法でトドメを刺すとトドメボーナスEXP2倍**（+1→+2）
- デザイン意図: 魔法使いがフィニッシャーとして名乗り出る動機。ファイア(P4)より火力は低いが経験値効率で勝る

### 5. 従者の指輪
- 種別: レリック
- レア度: Uncommon / 価格: 6G
- 効果: レベルアップ時のHP/MP回復量が**50%→80%**に増加
- デザイン意図: レベルアップ回復をヒール代わりに。「あと1キルでレベルアップ」のとき、ヒール温存の判断が生まれる

### 6. 先駆者の兜
- 種別: レリック
- レア度: Uncommon / 価格: 7G
- 効果: パーティ内で**レベルが最も低いキャラ**のダメージ+20%
- デザイン意図: トドメボーナスで1人だけ先行しがちな問題に対し、遅れたキャラ優先の動機を作る

### 7. 闘気の腕輪
- 種別: レリック
- レア度: Common / 価格: 5G
- 効果: 戦闘中にレベルアップが発生したとき、そのキャラの**次の攻撃ダメージ2倍**
- デザイン意図: 戦闘中レベルアップに報酬を付ける。強い一撃を次ターンに温存する判断

### 8. 師弟の絆
- 種別: 魔法
- レア度: Common / 価格: 5G
- 効果: 味方単体, MP3。対象に「導き」バフ付与（**次にその対象がトドメを刺すと+1ボーナスEXP**、1回消費）
- デザイン意図: 僧侶が「誰を育てたいか」を選ぶ支援魔法。攻防を犠牲にして育成を選ぶ判断

### 9. 古代の経典
- 種別: レリック
- レア度: Rare / 価格: 8G
- 効果: レベルアップ回数が**3回目と5回目**のとき、追加でSTR or INT +1獲得
- デザイン意図: 長期ランで価値が上がる投資型。知恵の書と組み合わせたレベルアップ回数増加プレイを促進

### 10. 戦場の教官
- 種別: 武器
- レア度: Rare / 価格: 8G
- 効果: 敵単体, Power2, ブレ±3, 耐久6。**この武器で攻撃するたび攻撃者のEXP+1**（トドメ不要）
- デザイン意図: 低火力と引き換えに確実にEXP蓄積。6回振れば6EXP=2キル相当だがDPS低下をチームが補う必要

## カテゴリB: 防御系（10個）

### 設計方針
既存の防御は事後回復主体（ヒール/再生）。事前防御/被ダメ軽減/カウンターを増やし「ヒールで戻すか、ダメージを受けないようにするか」の択を豊かにする。

---

### 1. 守護の盾
- 種別: 武器
- レア度: Uncommon / 価格: 8G
- 効果: **味方単体**, Power0, 耐久5。対象への次の被ダメージを**15軽減**（1ターン持続、1回消費）
- デザイン意図: 戦士の「攻撃を捨てて仲間を守る」アクション。武器枠1つを防御に割くビルド判断

### 2. 鍛錬の盾
- 種別: 武器
- レア度: Rare / 価格: 9G
- 効果: **味方単体**, Power0, 耐久∞。対象への次の被ダメージを**8軽減**。使用するたびに軽減値が**永続+1**（最大15）
- デザイン意図: 使い込むほど育つ盾。8→9→10と成長。攻撃できないターンが発生する明確なトレードオフ

### 3. 鉄壁の祈り
- 種別: 魔法
- レア度: Uncommon / 価格: 7G
- 効果: 味方単体, MP4。対象への次**2回**の被ダメージをそれぞれ**10軽減**
- デザイン意図: バリア(15×1回)との比較。単発にはバリア、連続攻撃には鉄壁の祈りが有利

### 4. 身代わりの人形
- 種別: レリック
- レア度: Uncommon / 価格: 7G
- 効果: 味方が致死ダメージを受けたとき、**HP1で耐える**（1ランに1回のみ）
- デザイン意図: ローHPビルドのセーフティネット。攻めた立ち回りを後押しする保険

### 5. 反射の外套
- 種別: レリック
- レア度: Uncommon / 価格: 7G
- 効果: 被ダメージの**30%を攻撃者に反射**（端数切捨て）
- デザイン意図: 反撃の棘(固定5)と別軸。弱攻撃には棘が強く(5>30%)、強攻撃(17+)には外套が強い

### 6. 生命の鎧
- 種別: レリック
- レア度: Rare / 価格: 9G
- 効果: **全被ダメージ-4**（最低1ダメージ）
- デザイン意図: 全ヒット確定軽減。多段攻撃やAoEに特に有効。ラン全体で累積価値が高い

### 7. 犠牲の壁
- 種別: 魔法
- レア度: Rare / 価格: 9G
- 効果: 味方単体, MP6。対象に「庇護」バフ付与。**次ターン、他の味方への攻撃を全て対象が肩代わり**（被ダメ-5軽減付き）
- デザイン意図: 戦士に庇護をかけて後衛を完全防御。祈り(確率)に対し確定で1ターン全受け

### 8. 魔力の盾
- 種別: 魔法
- レア度: Common / 価格: 5G
- 効果: 自分, MP3。次に受けるダメージを**MP消費で軽減**（1MP=3ダメージ軽減、自動消費、残MPが上限）
- デザイン意図: MPを防御リソースとして使う新軸。「攻撃MP vs 防御MP」のリソース配分判断

### 9. 癒しの風
- 種別: 魔法
- レア度: Common / 価格: 6G
- 効果: **味方全体**, MP5。味方全員の**HP8回復**
- デザイン意図: ヒール(単体30, MP5) vs 癒しの風(全体8, MP5)。AoE戦で効率的

### 10. 献身の杖
- 種別: 武器
- レア度: Common / 価格: 5G
- 効果: **味方単体**, Power0, 耐久4, INTスケール。対象の**HP12回復**
- デザイン意図: 僧侶の武器枠で使えるMP不要ヒール。魔法枠を攻撃に使いつつ最低限の回復を担保する「攻撃的僧侶」ビルド

## 元案との対応

| ユーザー元案 | 対応アイテム | 変更点 |
|------------|------------|--------|
| トドメでEXP2倍(魔法) | 覚醒の魔弾 | 全トドメ2倍は強すぎるので魔法固有効果に限定。Power3で火力を落として機会コスト明確化 |
| 取得EXP2倍+デメリット(レリック) | 修羅の証 | 「2倍」は過剰なので「トドメボーナス+1」に。デメリット=ゴールド-2Gで金策との二律背反 |
| 必要EXP半減(レリック) | 知恵の書 | 対数曲線と噛み合わないため「必要EXP-1」に変更。効果は近いが数式的に破綻しない |
| トドメで耐久温存(武器) | 魂喰いの剣 | ほぼそのまま。Power3に抑えてトドメ専用のポジショニング明確化 |
| 被ダメ-15の盾(武器) | 守護の盾 | 味方対象の武器として実装。耐久5で消耗品にし「いつ使うか」の判断を残す |
| ガードでSTR上昇(武器) | 鍛錬の盾 | STR上昇→軽減値上昇に変更。STR上昇だと攻撃転用されて防御文脈が薄れるため |

---

## バランス上の懸念と調整弁

### 経験値系
- **戦場の教官**(攻撃するだけでEXP+1)が強すぎる可能性 → Power値(2→1)、耐久(6→4)で調整可
- **知恵の書 + 修羅の証**の併用でレベリング加速しすぎ → 両方Rareにして出現率で制御

### 防御系
- **生命の鎧**(-4全軽減)がラン全体で圧倒的価値 → 軽減値(4→3)、価格(9→11)で調整可
- **魔力の盾** + **苦痛のリング**の無限ループ → 「軽減後のダメージを被ダメとする」仕様で制御
