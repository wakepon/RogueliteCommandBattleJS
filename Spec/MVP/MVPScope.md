# MVPのスコープ（範囲）定義

MVPでは**「3人パーティー制、1階層、コアシステム完備」**を目指します。

## このMVPで検証したいこと
* MVPでもちゃんと面白さを感じられるか
* 本実装前に想定外の仕様バグがないか
* A.Iと人の役割分担、開発スタイルはどのような形が良いか

## 実装するもの（Core）

* **ゲームループ:** 戦闘 → 報酬 → ストア → 次の戦闘（この1セットの繰り返し）。
* **3人パーティー制:** 戦士・魔法使い・僧侶の3人編成。コマンドスロット制で行動順管理。
* **リソース管理:** HP, MP, Gold, 武器使用回数の増減とUI表示。
* **戦闘計算式:** ダメージ計算ロジック完全実装。
* **ストア機能:** 商品のランダム陳列、売買、品揃え変更。
* **金利システム:** 所持金による利子ボーナス（戦略の核なので必須）。
* **敵AI:** 敵種別ごとに行動バリエーションが実装されている（確率テーブルによる行動選択、力溜め（自身/全味方）、連続攻撃、HPフェーズ切替、自己防御、自己回復、味方回復、仲間呼び（召喚）、全体攻撃（AoE）、弱体デバフ付与など）。討伐ターン制限も実装。
* **バランス調整ツール（Tuning Editor）:** DEV専用のパラメータ調整エディタ。BroadcastChannelによるリアルタイム反映。6カテゴリのパラメータを調整可能。

## 今回は見送るもの（Post-MVP）

* **ソウルシステム（永続強化）:** 今回はローグライク（死んだらリセット）として完結させる。
* **複雑な演出/ストーリー:** 世界観はテキストや色味（暗い背景）だけで表現。
* **3階層分のボリューム:** まずは「5〜7戦闘 + ボス」の1セットのみ作成。
