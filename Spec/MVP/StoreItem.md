# ストア・アイテム仕様

## ストア画面

* **表示タイミング:** 毎戦闘後に必ず表示（Stage 4の休憩/宝箱/修理後は表示なし）。
* **陳列数:** MVPでは固定で「武器/魔法枠: 3」「レリック/ポーション枠: 3」とする。
* **レイアウト:** 1画面に全商品6つを表示（タブ切り替えなし）。
* **品揃え変更 (Reroll):** 5G 消費で全商品を入れ替える。
  * 同じ商品が再度出現する可能性あり（完全ランダム）。
  * 価格上昇はMVPでは一旦なし。
* **売却:** 所持アイテムを選択後、売却ボタンで売却。
  * 価格: `購入価格 / 2` (端数切り捨て)。
  * 武器の場合: `floor((現在の使用回数 / 最大使用回数) * (購入価格 / 2))`。
* **購入制限:** 所持枠が上限の場合は購入不可（先に売却が必要）。
* **ポーション使用:** ストア画面でもポーションを使用可能。

### 商品抽選システム

商品の出現確率はScriptableObjectで管理する。

* **アイテムデータ:** 各アイテムに`価格`と`レアリティ`を個別設定。
* **レアリティごとの出現重み:** ステージごとに異なる重みを設定可能。
  * 例: 序盤はCommonの出現率が高く、後半はRare出現率が上がる。
* **商品構成:**
  * 武器/魔法枠（3つ）: 武器・魔法からランダムに3つ選択。
  * レリック/ポーション枠（3つ）: レリック・ポーションからランダムに3つ選択。
