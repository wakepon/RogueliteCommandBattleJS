# 全体フロー・サイクル

## ゲーム進行

1. **タイトル画面:** 「Start」のみ。
2. **マップ画面 (phase: 'map'):** 各ステージのノード情報（敵プレビュー含む）が事前に生成・表示される。
3. **ダンジョン進行（全21ステージ構成）:**

   **第一階層（Stage 1-7）:**
   * Stage 1: 必ず2体出現（ゴブリン+スライム、スライムx2、どぶネズミ+スライム等）
   * Stage 2: スライム+ゴブリンに加え、ゴブリンx2、どぶネズミx2、ヘドロスライム+スライムのパターンあり
   * Stage 3: オーク単体に加え、ゴブリン+シャーマン+スライム編成やアサシン単体のパターンあり
   * Stage 4: 休憩/宝箱/武器修理（選択）
   * Stage 5: オーク+シャーマン、アサシン+ゴブリン、スリープタイガー単体、ゴブリン+妖精+盾持ちゴブリン
   * Stage 6: ガーディアン+ゴブリン+シャーマン、ダークメイジ+ヘドロスライム、スリープタイガー+妖精、オーク+盾持ちゴブリン
   * Stage 7: 第一階層ボス（ドラゴン単体）

   **第二階層（Stage 8-14）:**
   * Stage 8: エリート2体編成（turnLimit=10）
   * Stage 9: 戦闘ステージ（アサシン+ガーディアン等）（turnLimit=10）
   * Stage 10: エリート3体編成（turnLimit=11）
   * Stage 11: 休憩/宝箱/武器修理（選択）、Stage 4と同様のイベントステージ
   * Stage 12: ドラゴン単体（turnLimit=12）
   * Stage 13: エリート3体編成（turnLimit=12）
   * Stage 14: 第二階層ボス（リッチまたはドラゴン+雑魚）（turnLimit=14）

   **第三階層（Stage 15-21）:**
   * Stage 15〜16: エリート3体編成（turnLimit=12）
   * Stage 17: ドラゴン+エリート編成（turnLimit=13）
   * Stage 18: 休憩/宝箱/武器修理（選択）、イベントステージ
   * Stage 19〜20: エリート3体編成（turnLimit=14）
   * Stage 21: 最終ボス（リッチ+エリート、またはドラゴン+エリート2体）（turnLimit=16）
   * floor_3_hp_multiplier（デフォルト3.0）とfloor_3_damage_multiplier（デフォルト2.5）が適用。

4. **ゲームオーバー:** 戦闘画面オーバーレイで表示（`battleState.isGameOver` フラグ制御）。**クリア:** 結果画面（詳細スタッツ表示）を表示しタイトルへ。

## 結果画面

ゲームクリア時に項目別逐次表示アニメーションで以下のスタッツを表示する。

| 項目 | 説明 |
| :--- | :--- |
| 到達Stage | どのステージまで進んだか |
| 最終レベル | 到達したレベル |
| 獲得ゴールド（累計） | ゲームを通じて獲得した総ゴールド |

* 討伐数表示は削除済み。
* メンバーカード単位でリソース変化量（HP/MP/EXP/武器耐久のbefore→after）を表示する。
* ResultState は `bonusEntries`（魔法/レリック効果による追加報酬の将来拡張枠、現状は空配列固定）、`memberDiffs`、`goldDiff` を含む。
* ゲームオーバーは戦闘画面オーバーレイで表示される（`battleState.isGameOver` フラグで制御）。

## Stage 4（Stage 11・Stage 18）: 休憩/宝箱/修理の選択

イベントステージでは戦闘ではなく、以下の3つから1つを選択する。

| 選択肢 | 効果 | 選択不可条件 |
| :--- | :--- | :--- |
| **休憩** | 最大HPの一定割合を回復（回復量はTuning Editorで調整可能） | なし |
| **宝箱** | ランダムなレリックを1つ獲得 | なし（枠満杯時は入れ替え） |
| **武器修理** | weaponIds指定による修理。選択したメンバーの全武器使用回数が一括で全回復（無料） | 修理対象の武器がない場合 |

### 武器修理の詳細
* EventLogic.ts内でweaponIds指定による特定武器修理形式。
* キャラクターを1人選択すると、そのメンバーが持つ全武器の使用回数が一括で全回復する。
* **選択不可条件:** 全メンバーの武器が全て使用回数が最大の場合は選択肢がグレーアウト。

### 宝箱の詳細（レリック枠満杯時）
* レリック枠が5/5で満杯の場合、先に獲得するレリックを表示。
* 「〇〇を獲得します。どれを売却しますか？」と確認し、所持レリックから1つを売却。
* 売却したレリックの金額がプレイヤーに加算される。

**注意:** イベントステージ後はストア画面が表示されない。

## 各Stageの流れ

### 戦闘Stageの流れ

```
戦闘開始
  ↓
ターン進行（勝利または敗北まで）
  ↓
勝利 → 報酬獲得（全敵のgoldReward合計）
  ↓
回復メニュー（phase: 'recovery'）
  ↓
ストア画面（毎戦闘後に表示）
  ↓
次のStageへ
```

### イベントStageの流れ
```
休憩/宝箱/武器修理の選択
  ↓
効果を適用
  ↓
次のStageへ（ストアなし）
```

## レベルアップ

* 敵を討伐するたびに経験値が加算される（全パーティーメンバーに1EXP、止めを刺したキャラはさらに+1EXP）。
* 必要討伐数に達するとレベルアップ。
* **成長方向選択（GrowthType）:** レベルアップ時に2択の成長方向を提示。5種のGrowthType（attack/hp/mp/balance/allBonus）からクラス別重み付きランダムで2択を生成。プレイヤーが選択して成長値が適用される。
* レベルアップ時のHP/MP回復: コード上のフォールバック値は25%（`levelup_hp_recovery_rate: 0.25`）。Tuning Editorで調整可能。
* 詳細は [BattleSystem.md](BattleSystem.md) を参照。

## 初期所持金

* ダンジョン開始時の所持金: **0G**（createInitialRunの設定値）。
