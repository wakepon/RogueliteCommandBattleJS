# 全体フロー・サイクル

## ゲーム進行

1. **タイトル画面:** 「Start」のみ。
2. **マップ画面 (phase: 'map'):** 各ステージのノード情報（敵プレビュー含む）が事前に生成・表示される。
3. **ダンジョン進行（全7ステージ構成）:**
   * Stage 1: スライム中心の雑魚戦（どぶネズミも出現）
   * Stage 2: スライム+ゴブリンに加え、どぶネズミx2やヘドロスライム+スライムのパターンあり
   * Stage 3: オーク単体に加え、ゴブリン+シャーマン+スライム編成やアサシン単体のパターンあり
   * Stage 4: 休憩/宝箱（選択）
   * Stage 5: オーク+シャーマン、アサシン+ゴブリン、スリープタイガー単体、ゴブリン+妖精+ゴブリン
   * Stage 6: オークロード+ゴブリン+シャーマン、ダークメイジ+ヘドロスライム、スリープタイガー+妖精、オークx2
   * Stage 7: ボス（ドラゴン）

4. **ゲームオーバー/クリア:** 結果画面（詳細スタッツ表示）を表示しタイトルへ。

## 結果画面

ゲームオーバー時・クリア時ともに以下のスタッツを表示する。

| 項目 | 説明 |
| :--- | :--- |
| 到達Stage | どのステージまで進んだか |
| 討伐数 | 倒した敵の総数 |
| 最終レベル | 到達したレベル |
| 獲得ゴールド（累計） | ゲームを通じて獲得した総ゴールド |

## Stage 4: 休憩/宝箱/修理の選択

Stage 4では戦闘ではなく、以下の3つから1つを選択する。

| 選択肢 | 効果 | 選択不可条件 |
| :--- | :--- | :--- |
| **休憩** | 最大HPの50%を回復（回復量はTuning Editorで調整可能） | なし |
| **宝箱** | ランダムなレリックを1つ獲得 | なし（枠満杯時は入れ替え） |
| **武器修理** | 手持ちの武器から最大2種類を選んで全回復（無料） | 修理対象の武器がない場合 |

### 武器修理の詳細
* 使用回数が最大未満の武器のみ選択可能。
* 手持ちの武器が2本未満の場合は、持っている分だけ修理可能。
* **選択不可条件:** 武器が0本、または全て使用回数が最大の場合は選択肢がグレーアウト。

### 宝箱の詳細（レリック枠満杯時）
* レリック枠が5/5で満杯の場合、先に獲得するレリックを表示。
* 「〇〇を獲得します。どれを売却しますか？」と確認し、所持レリックから1つを売却。
* 売却したレリックの金額がプレイヤーに加算される。

**注意:** Stage 4後はストア画面が表示されない。

## 各Stageの流れ

### 戦闘Stageの流れ（Stage 1-3, 5-7）
各ステージにはturnLimit値が設定されている（stage_1: 5, stage_2: 6, stage_3: 7, stage_5: 8, stage_6: 9, stage_7: 12）。

```
戦闘開始
  ↓
ターン進行（勝利または敗北まで）
  ↓
勝利 → 報酬獲得（ゴールド + 利子）
  ↓
ストア画面（毎戦闘後に表示）
  ↓
次のStageへ
```

### Stage 4の流れ
```
休憩/宝箱の選択
  ↓
効果を適用
  ↓
次のStageへ（ストアなし）
```

## レベルアップ

* 敵を討伐するたびに経験値が加算される（全パーティーメンバーに1EXP、止めを刺したキャラはさらに+1EXP）。
* 必要討伐数に達するとレベルアップ。
* レベルアップ効果: HP/MP部分回復（旧最大値の50%、上限は新最大値）+ クラス別成長値（戦士: HP+7/MP+1/STR+2、魔法使い: HP+3/MP+4/INT+2、僧侶: HP+5/MP+3/STR+1/INT+1）
* 詳細は [BattleSystem.md](BattleSystem.md) を参照。
