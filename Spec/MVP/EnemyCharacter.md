# 敵キャラクター仕様 (MVP用)

## 敵出現数

| 敵種別 | 出現数             |
| :--- |:----------------|
| 雑魚 | 1〜5体            |
| エリート | エリート1体 + 雑魚0〜3体 |
| ボス | ボス1体 + 雑魚0〜3体   |

敵のステータスはScriptableObjectで管理する

## 敵の所持金

敵は所持金を持っており、ゴールドラッシュで盗むことができる。

| 敵種別 | 所持金 |
| :--- | :--- |
| 雑魚 | 1G |
| エリート | 2G |
| ボス | 3G |

* **所持金は戦闘UIに表示されない**（隠し情報）。
* 盗んだ金額は戦闘終了時の報酬（BaseGold）とは別枠で加算される。
* 敵の所持金は戦闘ごとにリセットされる。

## 敵出現パターン

Stageごとに定義された固定編成のテーブルからランダムに選択される。

### Stage 1-2 編成テーブル（例）
| パターン | 編成 |
| :--- | :--- |
| A | スライム x1 |
| B | スライム x2 |
| C | スライム x3 |
| D | スライム x1, ゴースト x1 |

### Stage 5-6 編成テーブル（例）
| パターン | 編成 |
| :--- | :--- |
| A | スライム x2, ゴースト x2 |
| B | ゴースト x3 |
| C | スライム x4, ゴースト x1 |
| D | ゴースト x2 |

*※ 具体的な編成テーブルはバランス調整フェーズで決定*

## 敵のAI

### ターゲット選択
* MVPではプレイヤーが1ユニットのみのため、常にプレイヤーを攻撃対象とする。

---

## スライム (雑魚)
* **HP:** 20
* **攻撃:** 3
* **素早さ (Agi):** 2
* **所持金:** 1G
* **行動:** 単体攻撃のみ。

## ゴースト (雑魚)
* **HP:** 15
* **攻撃:** 2
* **素早さ (Agi):** 6
* **所持金:** 1G
* **行動:** 50%の確率で以下のどちらかを実行:
  * 通常攻撃
  * プレイヤーのMPを2削る（MPが2未満なら0まで削る）

## オーク (エリート)
* **HP:** 50
* **攻撃:** 8
* **素早さ (Agi):** 3
* **所持金:** 2G
* **行動パターン:** 以下のループ
  1. 力溜め
  2. 攻撃（2倍ダメージ = 16）
  3. 力溜め
  4. 攻撃（2倍ダメージ = 16）
  ...
* **力溜め:** 次の攻撃まで有効。攻撃時に攻撃力2倍。攻撃後に解除される。

## キメラ (ボス)
* **HP:** 150
* **攻撃:** 5
* **素早さ (Agi):** 4
* **所持金:** 3G
* **行動パターン:** 以下のループ
  1. 単体攻撃
  2. 毒攻撃（毒スタック+3）
  3. 連続攻撃（3ダメージ x 3回）

### 毒スタックシステム
* 毒はスタック制で、スタック数分のダメージを毎ターン受ける。
* 毎ターン終了時、スタックは1減少する。
* 戦闘終了時にリセットされる。
* 例: 毒スタック3 → 3ダメージ → スタック2 → 2ダメージ → ...
