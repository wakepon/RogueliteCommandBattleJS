# 敵キャラクター仕様 (MVP用)

## 敵出現数

| 敵種別 | 出現数             |
| :--- |:----------------|
| 雑魚 | 1〜5体            |
| エリート | エリート1体 + 雑魚0〜3体 |
| ボス | ボス1体 + 雑魚0〜3体   |

敵のステータスはJSONファイル(Enemies.json)で管理する。HPはパラメータ調整対象であり、Enemies.jsonを直接編集することで変更可能。

## 敵の報酬（goldReward）

敵は戦闘報酬として goldReward を持ち、全敵の合計が獲得ゴールドとなる。

| 敵種別 | goldReward |
| :--- | :--- |
| normal（雑魚） | 4G |
| elite（エリート） | 7G |
| boss（ボス） | 12G |

* 戦闘終了時、出現した全敵のgoldReward合計が報酬となる。
* 利子システムは削除済み。

## 敵のAI

### ターゲット選択
* 前衛（front）と後衛（back）の重み付き確率選択。前衛は後衛の2倍の確率で狙われる。
* 祈りバフ（targetRateUp）による被ターゲット率補正が適用される。

### 行動決定方式
* 全ての敵の行動は確率テーブル(weight方式)で決定される。固定ループパターンではない。
* 全敵のbehaviorは "attack" に統一。行動分岐はEnemyAI.ts内で敵IDごとに個別実装。

## スライム (雑魚)
* **HP:** 54 / **ATK:** 4 / **Agi:** 2 / **goldReward:** 4G
* **行動:** 100%体当たり（固定行動）

## ゴブリン (雑魚)
* **HP:** 90 / **ATK:** 5 / **Agi:** 4 / **goldReward:** 4G
* **行動:**
  * 60%: 斬りつける
  * 40%: 力溜め（力溜め中は渾身の一撃）

## どぶネズミ (雑魚)
* **HP:** 40 / **ATK:** 3 / **Agi:** 5 / **goldReward:** 4G
* **行動（確率テーブル）:**
  * 未召喚時: かみつく60% / 仲間呼び40%（hasSummonedフラグで管理）
  * 召喚後: かみつく100%

## ヘドロスライム (雑魚)
* **HP:** 50 / **ATK:** 3 / **Agi:** 2 / **goldReward:** 4G
* **行動:**
  * 泥かけ（攻撃＋weakness同時付与）50%
  * 体当たり50%

## シャーマン (雑魚)
* **HP:** 80 / **ATK:** 3 / **Agi:** 3 / **goldReward:** 4G
* **行動:**
  * 仲間鼓舞（他の生存敵全員に力溜めを付与）50%
  * 弱体の呪い（vulnerability付与）30%
  * 杖で殴る20%

## 妖精 (雑魚)
* **HP:** 45 / **ATK:** 2 / **Agi:** 6 / **goldReward:** 4G
* **行動:**
  * ヒール（最もHP割合が低い味方を回復、最大HPの30%回復）80%
  * タックル20%

## 盾持ちゴブリン (雑魚)
* **HP:** 70 / **ATK:** 3 / **Agi:** 3 / **goldReward:** 4G

* **HP:** 180 / **ATK:** 7 / **Agi:** 3 / **goldReward:** 7G
* **行動:**

  * 通常時: 60%力溜め、40%こづく

## アサシン (エリート)
* **HP:** 135 / **ATK:** 10 / **Agi:** 8 / **goldReward:** 7G
* **行動:**

  * 二連撃45%

## スリープタイガー (エリート)
* **HP:** 135 / **ATK:** 8 / **Agi:** 4 / **goldReward:** 7G
* **変身:** HP80%以下で表示名が「マッドタイガー」に変更される（transformName）。
* **行動:** HP比率によるフェーズ制。
  * **フェーズ1（HP > 80%）:** 寝返り100%。
  * **フェーズ2（HP ≤ 80%）:** 怒りの爪35% / あばれる20% / 乱れ引っかき（3連撃、各hitランダムターゲット選択）25% / 力溜め20%。
  * **力溜め中:** フェーズ無関係に大暴れ（2連撃、力溜め消費）。

## ダークメイジ (エリート)
* **HP:** 100 / **ATK:** 6 / **Agi:** 5 / **goldReward:** 7G
* **行動:**
  * MPドレイン（プレイヤーのMPを吸収）35%
  * 武器封印（weaponSeal）35%
  * ダークショット30%

## ガーディアン (エリート)

* **行動:**
  * 守護の盾（味方にシールド付与・applyShieldToAlly）40%
  * 庇う（applyGuard）30%
  * 体当たり30%

## ドラゴン (ボス)
* **HP:** 270 / **ATK:** 12 / **Agi:** 5 / **goldReward:** 12G
* **行動:** HP比率によるフェーズ制の確率テーブル。
  * **フェーズ1（HP > 50%）:** 50%切り裂く爪、30%自己再生（最大HPの30%回復）、20%火炎ブレス（AoE全体攻撃）。
  * **フェーズ2（HP <= 50%）:** 30%怒りの爪、30%猛火のブレス（AoE）、40%力溜め。
  * **力溜め中:** フェーズ無関係に渾身の一撃を使用。

## リッチ (ボス)
* **HP:** 220 / **ATK:** 8 / **Agi:** 4 / **goldReward:** 12G
* **行動:** HP比率によるフェーズ制。
  * **フェーズ1（HP > 50%）:** MPドレイン全体（mpDrainAll）35% / 呪い（weakness付与）35% / ダークショット30%。
  * **フェーズ2（HP ≤ 50%）:** 武器封印全体（weaponSealAll）35% / 暗黒ブレス（AoE）35% / 召喚（ヘドロスライム、unlimitedSummon）30%。

## 新規行動カテゴリ概要

| カテゴリ | 説明 |
| :--- | :--- |
| 召喚（仲間呼び） | 同種の敵を戦場に追加する。hasSummonedフラグにより1戦闘1回制限。 |
| 無制限召喚（unlimitedSummon） | 回数制限なしで召喚を行う（リッチのフェーズ2）。 |
| 仲間鼓舞 | 他の生存中の味方敵全員に力溜めバフを付与する。 |
| 自己回復 | 自分のHPを回復する。 |
| 味方回復 | 最もHP割合が低い味方敵のHPを回復する。 |
| AoE（全体攻撃） | プレイヤーパーティー全員にダメージを与える。 |
| 弱体デバフ複合（攻撃＋weakness） | 攻撃とweaknessデバフ付与を同時に行う（ヘドロスライムの泥かけ）。 |
| 弱体デバフ（weakness） | プレイヤーのダメージを低下させる持続ターン制デバフを付与する。 |
| 被ダメ増加（applyVulnerability） | vulnerabilityデバフを付与する（シャーマンの弱体の呪い）。 |
| 自己防御バフ（selfDefense） | 自分への被ダメージを軽減するバフを付与する。 |
| MPドレイン（mpDrain） | プレイヤーのMPを吸収する。 |
| 全体MPドレイン（mpDrainAll） | パーティー全員のMPを吸収する（リッチ）。 |
| 武器封印（weaponSeal） | ターゲットの武器を封印する（ダークメイジ）。 |
| 武器封印全体（weaponSealAll） | パーティー全員の武器を封印する（リッチのフェーズ2）。 |
| シールド付与（applyShieldToSelf） | 自身にシールドを付与する（盾持ちゴブリン）。 |
| シールド付与（applyShieldToAlly） | 味方にシールドを付与する（ガーディアン）。 |
| 庇う（applyGuard） | 味方への攻撃を代わりに受ける（ガーディアン）。 |
| ランダムターゲット連撃 | 複数回攻撃し、各ヒットでランダムにターゲットを選択する（スリープタイガーの「乱れ引っかき」が該当）。 |

### hasSummonedフラグ
* どぶネズミが持つ1戦闘限りの召喚制御フラグ。
* `hasSummoned: false` の状態でのみ仲間呼び行動を選択できる。
* 召喚実行後は `hasSummoned: true` に更新され、同一戦闘内での再召喚を防ぐ。
