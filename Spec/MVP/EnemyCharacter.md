# 敵キャラクター仕様 (MVP用)

## 敵出現数

| 敵種別 | 出現数             |
| :--- |:----------------|
| 雑魚 | 1〜5体            |
| エリート | エリート1体 + 雑魚0〜3体 |
| ボス | ボス1体 + 雑魚0〜3体   |

敵のステータスはJSONファイル(Enemies.json)で管理する。

## 敵の所持金

敵は所持金を持っており、盗む効果で入手できる。

| 敵 | 所持金 |
| :--- | :--- |
| スライム | 3G |
| ゴブリン | 6G |
| オーク | 18G |
| ドラゴン | 60G |

* **所持金は戦闘UIに表示されない**（隠し情報）。
* 盗んだ金額は戦闘終了時の報酬（BaseGold）とは別枠で加算される。
* 敵の所持金は戦闘ごとにリセットされる。

## 敵のAI

### ターゲット選択
* 前衛（front）と後衛（back）の重み付き確率選択。前衛は後衛の2倍の確率で狙われる。
* 祈りバフ（targetRateUp）による被ターゲット率補正が適用される。

### 行動決定方式
* 全ての敵の行動は確率テーブル(weight方式)で決定される。固定ループパターンではない。
* 全敵のbehaviorは "attack" に統一。行動分岐はEnemyAI.ts内で敵IDごとに個別実装。

## スライム (雑魚)
* **HP:** 18
* **ATK:** 4
* **素早さ (Agi):** 2
* **所持金:** 3G
* **行動（確率テーブル）:**
  * 100%: 体当たり（固定行動）

## ゴブリン (雑魚)
* **HP:** 28
* **ATK:** 5
* **素早さ (Agi):** 4
* **所持金:** 6G
* **行動（確率テーブル）:**
  * 60%: 斬りつける
  * 40%: 全力で斬りつける

## オーク (エリート)
* **HP:** 55
* **ATK:** 7
* **素早さ (Agi):** 3
* **所持金:** 18G
* **行動（確率テーブル）:**
  * 力溜め中: 100%で渾身の一撃（力溜めを消費）
  * 通常時: 60%力溜め、40%殴りつける

## ドラゴン (ボス)
* **HP:** 160
* **ATK:** 12
* **素早さ (Agi):** 5
* **所持金:** 60G
* **行動:** HP比率によるフェーズ制の確率テーブル。
  * **フェーズ1（HP > 50%）:** 50%爪で引っ掻く、30%尻尾で薙ぎ払う、20%火炎ブレス。
  * **フェーズ2（HP <= 50%）:** 30%爪で引っ掻く、30%火炎ブレス、20%力溜め、20%連続攻撃。
  * **力溜め中:** フェーズ無関係に渾身の一撃を使用。
