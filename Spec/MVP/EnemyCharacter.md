# 敵キャラクター仕様 (MVP用)

## 敵出現数

| 敵種別 | 出現数             |
| :--- |:----------------|
| 雑魚 | 1〜5体            |
| エリート | エリート1体 + 雑魚0〜3体 |
| ボス | ボス1体 + 雑魚0〜3体   |

敵のステータスはJSONファイル(Enemies.json)で管理する。HPはパラメータ調整対象であり、Enemies.jsonを直接編集することで変更可能。

## 敵のAI

### ターゲット選択
* 前衛（front）と後衛（back）の重み付き確率選択。前衛は後衛の2倍の確率で狙われる。
* 祈りバフ（targetRateUp）による被ターゲット率補正が適用される。

### 行動決定方式
* 全ての敵の行動は確率テーブル(weight方式)で決定される。固定ループパターンではない。
* 全敵のbehaviorは "attack" に統一。行動分岐はEnemyAI.ts内で敵IDごとに個別実装。

  * **力溜め中:** フェーズ無関係に渾身の一撃を使用。

## 新規行動カテゴリ概要

| カテゴリ | 説明 |
| :--- | :--- |
| 召喚（仲間呼び） | 同種の敵を戦場に追加する。hasSummonedフラグにより1戦闘1回制限。 |
| 仲間鼓舞 | 他の生存中の味方敵全員に力溜めバフを付与する。 |
| 自己回復 | 自分のHPを回復する。 |
| 味方回復 | 最もHP割合が低い味方敵のHPを回復する。 |
| AoE（全体攻撃） | プレイヤーパーティー全員にダメージを与える。 |
| 弱体デバフ複合（攻撃＋weakness） | 攻撃とweaknessデバフ付与を同時に行う（ヘドロスライムの泥かけ）。 |
| 弱体デバフ（weakness） | プレイヤーのダメージを低下させる持続ターン制デバフを付与する。 |
| 自己防御バフ（selfDefense） | 自分への被ダメージを軽減するバフを付与する。 |
| MPドレイン | プレイヤーのMPを吸収する。 |
| ランダムターゲット連撃 | 複数回攻撃し、各ヒットでランダムにターゲットを選択する（isRandomTarget: trueフラグで制御）。スリープタイガーの「乱れ引っかき」が該当。 |

### hasSummonedフラグ
* どぶネズミが持つ1戦闘限りの召喚制御フラグ。
* `hasSummoned: false` の状態でのみ仲間呼び行動を選択できる。
* 召喚実行後は `hasSummoned: true` に更新され、同一戦闘内での再召喚を防ぐ。
