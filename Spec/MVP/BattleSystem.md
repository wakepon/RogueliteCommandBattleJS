# 戦闘システム仕様

## ターン進行

### 1. ターン開始時
* バフ/デバフのターン経過処理（毒ダメージ等）。
* 討伐ターンカウント減少。0未満の場合、ペナルティダメージ発生。

### 2. 行動順の決定
* 素早さ(Agi)の高い順に行動する。
* **同じ素早さの場合:** プレイヤー優先。
* **敵同士が同じ素早さの場合:** 左から順に行動。

### 3. 各キャラクターの行動
* **プレイヤー:** 武器/魔法を選択 → ターゲット選択 → 実行。
  * 実行時、対応するリソース（MP、使用回数、HP、Gold）を消費。
  * **リソース不足時は選択不可**とする。
  * **ターゲット選択:** 敵をタップ/クリックで直接選択。
* **敵:** 敵の行動ロジックに基づき攻撃。

### 4. ポーション
* ポーションは**ターン消費なし（フリーアクション）**で使用可能。
* **使用タイミング:** プレイヤーの行動ターン中のみ（敵ターン中は使用不可）。
* **使用回数制限:** 1ターンに何回でも使用可能（所持数が上限）。
* 戦闘中・ストア画面の両方で使用可能。

### 5. 終了判定
* 敵全滅 → 勝利（報酬画面へ）。
* 味方HP0 → 敗北（ゲームオーバー）。

## 討伐ターン制限

各戦闘にはターン制限があり、超過するとペナルティダメージを受ける。

| 敵種別 | 制限ターン数 |
| :--- | :--- |
| 雑魚 | 5ターン |
| エリート | 7ターン |
| ボス | 9ターン |

* **複数の敵種が混在する場合:** 最も強い敵（ボス > エリート > 雑魚）の制限ターン数を適用する。
  * 例: ボス + 雑魚3体 → 9ターン制限
* **ペナルティダメージ:** `5 × 2^(超過ターン数)` ダメージ
  * 例: 1ターン超過 → 10ダメージ、2ターン超過 → 20ダメージ、3ターン超過 → 40ダメージ

## ダメージ計算式（最重要）

**シンプル構造**を採用:

```
最終ダメージ = (Str/Int × (ItemPower + 固定加算)) × バフ倍率 × ブレ補正
```

* **UnitStat:** 武器/パンチなら筋力(Str)、魔法なら知力(Int)。
* **ItemPower:** 武器/魔法に設定された基本威力。パンチは0。
* **固定加算:** 鋭い砥石など、武器/パンチ攻撃時に加算されるボーナス。
* **バフ倍率:** 狂戦士の仮面などの倍率効果を**加算**。未適用時は1.0。
  * 例: 狂戦士の仮面(+0.5) → 倍率1.5
  * 複数のバフ倍率は加算（例: 狂戦士 + 将来のバフ → 1.0 + 0.5 + 0.3 = 1.8）

### マッスルアップの計算
* マッスルアップ（筋力+3）は**ステータス加算**として処理。
* Str 5 の状態でマッスルアップ使用 → Str 8 として計算。
* バフ倍率には影響しない。

### ダメージ/回復ブレ幅
* **ブレ補正:** 正規分布に基づくランダム係数（0.90～1.10）。
* **分布:** 正規分布（平均1.0）、範囲外の値は0.90～1.10にクランプ。
* **適用対象:** ダメージ・回復の両方に適用。
* 計算例: 基礎ダメージ100の場合、最終的に90～110のダメージになる。

### 端数処理
* 浮動小数点は計算途中で保持し、**最終ダメージで切り捨て（floor）**。
* 回復量の端数も切り捨て（floor）。
* HP回復は最大HPでキャップされる（オーバーヒールなし）。

### 全体攻撃
* 全体攻撃（ファイアストーム等）は**各敵に同じダメージ**を与える。

## バフ/デバフ

### 持続ターン数
効果ごとに個別設定する。

| 効果 | 持続 |
| :--- | :--- |
| マッスルアップ（筋力+3） | 戦闘終了まで |
| 毒 | スタック制（後述） |
| 力溜め | 次の攻撃まで（攻撃後解除） |

### 毒システム（スタック制）
* 毒はスタックされ、毎ターン **スタック数分のダメージ** を受ける。
* 毎ターン終了時、スタックは1減少する。
* 戦闘終了時にリセットされる。
* 例: 毒スタック3 → 3ダメージ → スタック2に減少 → 2ダメージ → ...

## レリック効果の詳細

### 効果の適用タイミング

| レリック | 効果タイミング |
| :--- | :--- |
| 戦士の腕輪 | 常時（ステータス画面に反映） |
| 魔術師の帽子 | 常時（ステータス画面に反映） |
| 鋭い砥石 | 武器/パンチ攻撃実行時にダメージ計算に+3加算（魔法は対象外） |
| 貯金箱 | 報酬計算時（利子上限を10Gに変更） |
| 狂戦士の仮面 | 攻撃実行時にHP判定（50%以下でバフ倍率+0.5） |

### レリックの重複
* 同じレリックを複数所持可能。
* 効果は加算される（例: 戦士の腕輪 x2 → 筋力+4）。

### レリック効果の永続性
* レリック効果はダンジョン内で永続する。
* ゲームオーバー/クリア時にリセットされる（ソウルシステム未実装のため）。

## レベルアップシステム

### 経験値
* **経験値 = 敵討伐数**（シンプルにカウント）

### レベルアップ条件
* 必要討伐数 = `floor(3 × log2(現在のレベル + 1))`

| レベル | 必要討伐数 | 累計討伐数 |
| :--- | :--- | :--- |
| 1→2 | 3体 | 3体 |
| 2→3 | 5体 | 8体 |
| 3→4 | 6体 | 14体 |
| 4→5 | 7体 | 21体 |

### レベルアップ効果
* **最大HP/MPの増加:** 最大HP +5、最大MP +2
* **HP/MP回復:** 最大HP/MPの50%を回復（端数切り捨て）
* **ステータス上昇:** 全ステータス（Str, Int, Agi）+1

### レベルアップのタイミング
* **敵討伐時に即時発動**。
* 戦闘中にHP/MP回復が発生するため、ピンチの場面での逆転が可能。

## 報酬処理

勝利時、以下の計算でゴールドを加算する。

* **BaseGold:** 戦闘に出現した**最も強い敵**の報酬のみ。
  * 雑魚(3G), エリート(5G), ボス(10G)
  * 例: ボス + 雑魚3体の戦闘 → 10Gのみ（雑魚の報酬は加算されない）
* **Interest (利子):** min( floor(CurrentGold / 5), 5 )。
  * 例: 所持金23Gの場合、利子は4G。所持金100Gでも利子は上限の5G。
* **盗んだゴールド:** ゴールドラッシュで盗んだ金額は別枠で加算される。
